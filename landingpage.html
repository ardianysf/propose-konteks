Agents

Plan

Read the note and the code. Write what gets built, what done means, and a ceiling.

Build

On its own branch, across every repo the change touches, with a second agent reviewing.

Check

Click through the work in a real browser. Keep the screenshots. Say what could not be verified.

Watch

Read the logs and alerts. Catch the issue first. Work the fix.

The one rule

No agent has more authority than the people around it. Nothing costs money before a person says yes. Every decision that matters comes back to a person.

How it works

Initiatives, issues, releases. A person can steer at every step.

What is moving?

Initiative

  1. 01You write a note. Teammates comment and react.
  2. 02A plan comes back with a ceiling, set from the agent’s own calibrated estimate.
  3. 03You say yes.
  4. 04The agent builds, with a second agent reviewing.
  5. 05It checks its own work in a real browser.
  6. 06You accept. Tested pull requests and a receipt.
What is wrong?

Issue

  1. 01The agent catches the alert first and opens an issue with a severity.
  2. 02It contains the damage.
  3. 03It proposes the fix. You say yes.
  4. 04A normal build if the fix needs code. Resolved, timeline kept.
What shipped?

Release

  1. 01Accepted work gathers into a release candidate.
  2. 02You decide when it ships.
  3. 03The release reads like a post the team can react to.

The catalog

Each product lives in a Software System.

A software catalog of its repos and components. Every session reads it, so the next note starts knowing the software.

One set of rules

Authority, money, evidence. The same for every person and every agent.

Enforced on the server, never by a prompt.

Authority

Enterprise IAM is built in.

  • Least-privilege roles you define, and groups
  • Access scoped to exact Systems
  • Temporary access with a reason and an expiry
  • Service accounts that can never hold human authority
  • One audit trail across app, API, and MCP

Money

Every piece of work is quoted as a ceiling before it runs.

  • Your yes locks the ceiling
  • Quotes calibrated from your own delivery history
  • New automation runs in shadow on real work before it may decide anything
  • Provider bill shown separately, never marked up

Evidence

A permanent receipt for every delivery.

  • Quoted, settled, provider cost, evidence
  • The agent that builds never judges its own work
  • Budgets stop before the line, not after
  • Retries have limits; real decisions come back to a person
