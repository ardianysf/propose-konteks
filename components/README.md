# Components

What every part is built from. Change a value here and the landing page, design system, login and app all follow.

| Folder | What it does |
|---|---|
| `tokens/` | `tokens.css` (colour light and dark, type, space, radius, shadow, motion), `fonts.css`, `fonts-alt.css`. The only place raw colours may appear. |
| `css/` | `base.css` (reset, body, focus) and `components.css` (every component). Checked by `tools/lint_colors.py`. |
| `js/` | `ui.js` (icons, dates, avatars, drawer, modal, dialog, menu, popover, toast, sound), `composer.js` (the chat composer), `kx-views.js` (the View tab across the four parts). |
| `react/` | React + Tailwind versions of the main components (`src/`), with a demo build (`demo/`). |
| `package/` | The developer handoff for the live codebase: `tokens.css`, `tokens.live-map.css`, `tailwind.preset.js`, `components.scoped.css`, `inventory.csv`, `AGENTS.md`, React copies. Mostly generated by `tools/make_package.py`; `README.md`, `AGENTS.md` and `.stylelintrc.json` are written by hand. |
